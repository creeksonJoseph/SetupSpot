# SetupSpot

SetupSpot is a full-stack platform for sharing workspace setups with interactive,
shoppable product hotspots. It combines a React/Vite frontend with a FastAPI
backend, PostgreSQL and pgvector, semantic recommendations, search, caching,
image hosting, and OAuth authentication.

## Project Structure

```text
backend/   FastAPI API, services, database models, and background jobs
frontend/  React/Vite web application
docs/      Setup, architecture, security, and design documentation
```
